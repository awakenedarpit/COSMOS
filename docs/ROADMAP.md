# COSMOS Roadmap

## V1 — Command center

Shipped in the initial release: premium responsive shell, dashboard overview, study orbit, semester journey, progress cards, task queue, schedule surface, activity timeline, focus-session flow, syllabus, goals, analytics, roadmap, knowledge base, settings, local task persistence, and GitHub Pages automation.

## V1.1 — Reliable personal data

- Add schema-versioned local storage.
- Move collections to IndexedDB.
- Add import/export for the complete workspace.
- Add task editing, recurring tasks, filters, and a real backlog.
- Add calendar date modeling rather than presentation-only schedule seed data.

## V1.2 — Review and recovery

- Add weekly review with completed work, missed work, and next-week planning.
- Add “I’m behind” mode that turns unfinished work into a calm recovery plan.
- Add smart priority scoring with transparent inputs.
- Add richer study session history and subject-level time attribution.

## V2 — Optional cloud

- Add authentication.
- Add Supabase-backed sync with offline-first conflict handling.
- Add multi-device workspace recovery.
- Add explicit privacy and data export controls.

## V2+ — Intelligence

- Add an AI copilot that summarizes the user's own data and proposes schedules.
- Add natural-language task capture with user confirmation before mutations.
- Add intelligent syllabus pacing and exam-aware recommendations.
- Add multi-agent workflows for planning, review, and research while keeping the user in control.

## Non-goals

COSMOS should not become a noisy gamification product, a social feed, or an opaque automation layer that silently changes academic commitments. Every recommendation should remain understandable, reversible, and subordinate to the user's priorities.
